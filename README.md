# Неофициальная база СтатГрад (StatGrad) и ЕГКР для 11 класса — v1.12

Открытая независимая база заданий **СтатГрад / Статград (StatGrad)** и **ЕГКР** для 11 класса: задания, ответы, источники, полные страницы, визуальные материалы и проверенная галерея кропов.

Проект предназначен для учеников, преподавателей, методистов, исследователей образовательных данных и разработчиков учебных инструментов. Это готовая пользовательская версия единой базы с отдельным, проверенным человеком task-aware crop-слоем.

> **Неофициальный независимый проект.** Проект не связан со СтатГрад, StatGrad, ЕГКР или экзаменационными органами и не представляет их позицию.

## Что внутри

- `statgrad_master_v1_12_user_edition.xlsx` — 6842 задания, канонический каталог 1760 VIS_ID и лист `Кропы`;
- `visual_gallery/index.html` — офлайн-галерея Original / Cropped;
- `manifests/task_focus_approved_v1_12.json` — 379 проверенных решений Task ID × VIS_ID;
- `manifests/task_crop_links_v1_12.csv` — переносимые ссылки на итоговые assets.

## Как пользоваться

1. Скачайте готовый релиз проекта.
2. Полностью распакуйте архив в отдельную папку.
3. Откройте книгу и начните с листа `README`.
4. Для визуальной проверки откройте `visual_gallery/index.html`.

Лист `Визуал` сохраняет канонический исходный слой, а лист `Кропы` содержит только производные изображения, прошедшие ручной QA.

Оригинальные assets не перезаписывались: crop-слой является отдельным производным представлением.
