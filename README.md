# Неофициальная база StatGrad / ЕГКР 11 класса — v1.11 User Edition

Удобная пользовательская версия единой базы заданий 11 класса с готовой офлайн-галереей визуальных материалов.

> **Неофициальный независимый проект.** Проект не связан со StatGrad, ЕГКР или экзаменационными органами и не представляет их позицию.

## Что скачать

В GitHub Release доступны два основных файла:

- `statgrad_master_v1_11_user_edition.xlsx` — отдельная рабочая таблица;
- `statgrad_v1_11_complete.zip` — полный комплект: таблица, лицензии и готовая визуальная галерея.

После распаковки полного комплекта откройте:

```text
visual_gallery/index.html
```

Галерея работает офлайн и не требует сервера. В ней есть поиск и фильтры по предмету, версии, варианту, Task ID, VIS_ID, типу визуала и источнику. Изображения открываются в полном размере, аудио воспроизводится прямо в карточке.

## Книга

Файл `statgrad_master_v1_11_user_edition.xlsx` содержит три листа:

1. **README** — назначение базы, порядок работы и расшифровка флагов;
2. **Задания** — 6842 записи с фильтрами и сохранёнными аудиторскими статусами;
3. **Визуал** — каталог 1760 `VIS_ID` с источниками, страницами, QA-статусами, SHA-256 и прямыми локальными ссылками на галерею.

## Как пользоваться

Откройте книгу в Excel, LibreOffice Calc или совместимом табличном редакторе. Начните с листа `README`, затем используйте фильтры листа `Задания`. Для визуала используйте ссылку `Галерея` на листе `Визуал` либо поиск в `visual_gallery/index.html`.

Флаги `SOURCE_GAP`, `ATTACHMENT_MISSING`, `KEY_MISMATCH`, `TASK_DEFECT`, `AUDIO_PENDING` и аналогичные не являются ошибками экспорта: они честно фиксируют состояние первичного источника.

## Проверка целостности

В полном комплекте находятся контрольные суммы:

```bash
sha256sum -c release_checksums.sha256
```

Внутри `visual_gallery/` есть отдельный `checksums.sha256` для всех опубликованных assets.
