# Неофициальная база StatGrad / ЕГКР 11 класса — v1.12 Cropped Visual Edition

Удобная пользовательская версия единой базы заданий 11 класса с отдельным, проверенным человеком task-aware crop-слоем.

> **Неофициальный независимый проект.** Проект не связан со StatGrad, ЕГКР или экзаменационными органами и не представляет их позицию.

## Что внутри

- `statgrad_master_v1_12_user_edition.xlsx` — 6842 задания, канонический каталог 1760 VIS_ID и лист `Кропы`;
- `visual_gallery/index.html` — офлайн-галерея Original / Cropped;
- `manifests/task_focus_approved_v1_12.json` — 379 проверенных решений Task ID × VIS_ID;
- `manifests/task_crop_links_v1_12.csv` — переносимые ссылки на итоговые assets.

## Контрольные показатели

- заданий: **6842**;

## Как пользоваться

Откройте книгу и начните с листа `README`. Лист `Визуал` сохраняет канонический исходный слой, а лист `Кропы` содержит только производные изображения, прошедшие ручной QA. Для сравнения откройте `visual_gallery/index.html`.

Оригинальные assets не перезаписывались: crop-слой является отдельным производным представлением.
