Неофициальная база СтатГрад и ЕГКР для 11 класса

Открытая независимая база заданий СтатГрад / Статград (StatGrad) и ЕГКР: задания, ответы, источники, полные страницы и проверенная галерея кропов.

Что входит в проект

  • единая Excel-база для 11 класса;
  • ответы, источники и статусы проверки;
  • полные страницы исходных материалов;
  • офлайн-галерея Original / Cropped;
  • проверенный человеком crop-слой;
  • манифесты и контрольные суммы SHA-256.

Как начать

  1. Скачайте последний релиз.
  2. Полностью распакуйте архив.
  3. Откройте книгу и начните с листа README.
  4. Для просмотра изображений откройте visual_gallery/index.html.
